# فرم مرسولات تیپاکس (نسخه‌ی وب)

نسخه‌ی تحت‌وبِ همون اپی که برای اندروید ساخته شد — همون فرم ۴ فیلدی، ساخت فایل اکسل رسمی تیپاکس، قفل رمز + فعال‌سازی دستگاه، تایپ صوتی. فقط به جای نصب، با یه لینک تو مرورگر (هم اندروید، هم آیفون) باز می‌شه.

لینک زنده‌ی صفحه (بعد از فعال شدن GitHub Pages):

https://javazi3224.github.io/tipax-web/

اولین بار که کسی این لینک رو باز کنه، یه «کد دستگاه» می‌بینه که باید برای احسان بفرسته تا با activation_tool.html کد فعال‌سازی‌شو بسازه.
